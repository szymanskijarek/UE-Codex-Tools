## If something else moved

Send it anyway. Claude checks each twin against its original: if more than

## Importing

Upload the files (any names; say which is which if unsure). Claude saves them
as `art/news/desk-<guest>-<expression>[-b].png`, converts them to WebP in
`apps/client/src/news/art/`, and the game plays them straight away: twins flap
while the guest talks, `hurt` shows when a script line hits the guest seat
with `"chair": "guest"` or sets `"mood": "hurt"`.
